# Jeanne Book – Journalling Book Hardcover Custom

Website toko HTML, CSS, dan JavaScript murni. Pelanggan bisa memilih ukuran (A5/B5), isi (100/200 lembar), nama, gaya cover (klasik atau watercolor bunga), ikon, warna, dan pola dengan pratinjau langsung, unggah foto sendiri untuk cover, masukkan ke keranjang, lalu checkout lewat WhatsApp.

## Publish ke GitHub Pages
1. Buat repo publik di https://github.com/new dengan nama `tokobukujeanne`.
2. Unggah ketiga file (index.html, style.css, script.js) langsung ke root repo, lalu Commit.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. Link: `https://USERNAME-GITHUB.github.io/tokobukujeanne/`

## Yang bisa diubah
- Nomor WhatsApp: `WA` di `script.js` (format 62xxxxxxxxxx).
- Harga: `PRICE` di `script.js`.
- Alamat, email, dan sosmed: `index.html`.
